# Client state

| Skill | Install source | Use when |
| --- | --- | --- |
| `jotai` | `jotaijs/jotai-skills` | Jotai atoms, derived state, persistence, or React integration recur. |
| `zustand` | `pproenca/dot-skills` | Zustand store boundaries, selectors, render behavior, persistence, SSR, or TypeScript recur. |

For server data and caching with TanStack Query, use [TanStack Intent](tanstack.md). Choose a state skill only for the state library actually used by the project.
