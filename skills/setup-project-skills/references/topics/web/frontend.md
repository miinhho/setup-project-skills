# Frontend frameworks

| Skill | Install source | Use when |
| --- | --- | --- |
| `vue-patterns` | `affaan-m/ECC` | Vue Composition API, Pinia, or Vue Router work recurs. |
| `nuxt4-patterns` | `affaan-m/ECC` | Nuxt 4 application work recurs. |
| `angular-developer` | `angular/angular` | Angular components, signals, forms, or dependency injection recur. |
| `angular-new-app` | `angular/angular` | A new Angular application is created with current Angular CLI defaults. |
| `svelte-core-bestpractices` | `sveltejs/ai-tools` | Svelte component and reactivity work recurs. |
| `svelte-code-writer` | `sveltejs/ai-tools` | Svelte 5 documentation lookup and component analysis through its CLI recur. |
| `react-router-framework-mode` | `remix-run/agent-skills` | React Router framework-mode routes, loaders, or actions recur. |
| `react-router-data-mode` | `remix-run/agent-skills` | React Router data-mode navigation or loaders recur. |
| `react-router-declarative-mode` | `remix-run/agent-skills` | React Router JSX routes without loaders or actions recur. |
| `astro` | `astrolicious/agent-skills` | Astro pages or integrations recur. |
| `storybook` | `pproenca/dot-skills` | Storybook 9/10 configuration, CSF3 stories, interaction tests, accessibility gates, or docs recur. |
| `shadcn` | `shadcn-ui/ui` | shadcn/ui component installation or customization recurs. |
| `migrate-radix-to-base` | `shadcn-ui/ui` | A shadcn project migrates component primitives from Radix UI to Base UI. |
| `material-ui-styling` | `mui/material-ui` | MUI styling APIs and theme integration recur. |
| `material-ui-theming` | `mui/material-ui` | MUI theme customization recurs. |
| `material-ui-nextjs` | `mui/material-ui` | MUI integrates with Next.js App or Pages Router, SSR, fonts, or Emotion cache. |
| `material-ui-tailwind` | `mui/material-ui` | MUI and Tailwind CSS share cascade layers, tokens, utilities, or portal styling. |

For React or Next.js, open their separate field files. For CSS, Tailwind CSS, or UnoCSS, open [CSS and styling](css.md). For embedded WebView pages, open [WebView](webview.md). For Jotai or Zustand, open [client state](state.md). For Vite, open [build tooling](../infrastructure/build-tooling.md). For TanStack libraries, use [Intent](tanstack.md).
