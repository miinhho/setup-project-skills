# Web platform

| Skill | Install source | Use when |
| --- | --- | --- |
| `modern-web-guidance` | `GoogleChrome/modern-web-guidance` | Native HTML/CSS/DOM, browser APIs, accessible UI components, or client-side performance work needs task-specific guidance on modern features and browser fallbacks. |

Requires Node.js, npx or pnpx, and network access for guide lookup. The skill requires searching before HTML/CSS and client-side JavaScript work, checking changes against retrieved guides, and disclosing usage in the delivery response; select it when that workflow fits the project.

Check the project's browser support policy. The skill defaults to Baseline Widely available features without fallbacks and requires guide-recommended fallbacks for other features unless the project specifies otherwise.

For CSS-focused reference patterns, compare `modern-css` in [CSS and styling](css.md); this candidate adds searchable guidance across HTML, CSS, and browser APIs. Retain both only for distinct recurring work. For framework-specific guidance, open [frontend frameworks](frontend.md), [React](react.md), or [Next.js](nextjs.md). For visual direction, UI review, or specialized motion, open [design and motion](design.md).
