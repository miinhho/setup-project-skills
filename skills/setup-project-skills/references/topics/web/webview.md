# Embedded WebView pages

| Skill | Install source | Use when |
| --- | --- | --- |
| `webview-bridge-pages` | `voidmatcha/frontend-niche-skills` | The web page inside React Native, WKWebView, Android WebView, or Flutter owns a native bridge, lifecycle, viewport, or compatibility issue. |
| `expo-dom` | `expo/skills` | An Expo app renders DOM components inside a native WebView. |

These cover the page inside a WebView. For the native host, open [Tauri and Electron](../desktop/desktop.md), [Swift WebKit](../languages/swift.md), or [Android](../mobile/android.md). Confirm which side owns the failure before proposing a skill.
