# Retrieval-augmented generation

| Skill | Install source | Use when |
| --- | --- | --- |
| `rag-implementation` | `wshobson/agents` | Document ingestion, chunking, retrieval, and grounded generation recur across tools. |
| `embedding-strategies` | `wshobson/agents` | Embedding model choice, chunking, or index update strategy recurs. |
| `hybrid-search-implementation` | `wshobson/agents` | Dense and keyword retrieval must be combined and measured. |
| `evaluate-rag` | `hamelsmu/evals-skills` | Retrieval recall, reranking, and generation faithfulness need separate evaluation. |
| `langchain-rag` | `langchain-ai/langchain-skills` | The project implements RAG with LangChain. |

For a specific vector database, open [data stores](../db/databases.md) or [Redis and MongoDB](../db/document-cache.md) only when that provider is in use.
