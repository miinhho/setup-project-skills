# Review

| Skill | Install source | Use when |
| --- | --- | --- |
| `code-review` | `mattpocock/skills` | A reviewer compares a diff with repository standards and the originating spec. |
| `ponytail-review` | `DietrichGebert/ponytail` | A separate review should identify unnecessary abstractions or dependencies. |
| `find-bugs` | `getsentry/skills` | Branch changes need a focused bug and vulnerability pass. |

Inspect `code-review` before installing: its upstream workflow dispatches subagents, so align the project copy with the harness's reviewer node. For browser and test methods, open [testing](testing.md).
