# Testing

| Skill | Install source | Use when |
| --- | --- | --- |
| `react-testing` | `affaan-m/ECC` | React component and hook tests using RTL and Vitest or Jest recur. |
| `vitest` | `pproenca/dot-skills` | Vitest setup, async tests, mocks, snapshots, coverage, or test performance recur. |
| `react-testing-library` | `pproenca/dot-skills` | React tests need user-centered queries, interactions, async behavior, and maintainable assertions. |
| `javascript-typescript-jest` | `github/awesome-copilot` | A project specifically uses Jest for JavaScript or TypeScript tests. |
| `ai-regression-testing` | `affaan-m/ECC` | Agent-written code needs targeted regression coverage. |
| `e2e-testing` | `affaan-m/ECC` | Playwright E2E tests or flaky browser tests recur. |
| `agent-browser` | `vercel-labs/agent-browser` | Browser or Electron flows need hands-on QA. |
| `qa` | `browser-use/browser-use` | The project uses Browser Use cloud for scored website QA. |
| `playwright-cli` | `microsoft/playwright-cli` | Browser checks or Playwright test inspection recur. |
| `cypress-tap` | `cypress-io/ai-toolkit` | Cypress 15.21+ open-mode sessions need agent-driven reruns, logs, snapshots, DOM, or accessibility inspection. |
| `cypress-docs` | `cypress-io/ai-toolkit` | Cypress API or configuration questions need current official documentation lookup. |
| `webapp-testing` | `anthropics/skills` | Local web app flows need Playwright-driven verification. |
| `java-junit` | `github/awesome-copilot` | Standalone JUnit 5 and parameterized Java tests recur. |
| `django-tdd` | `affaan-m/ECC` | Django or DRF features are developed test-first. |
| `k6` | `grafana/skills` | Load-test scripts and performance checks recur. |

For independent code review, open [review](review.md).
For language-specific test patterns, open the matching [Python](../languages/python.md), [Go](../languages/go.md), [Rust and Tokio](../languages/rust.md), or [Spring Boot](../services/spring.md) map.
For C++ tests, open [C++](../languages/cpp.md). For Flutter tests, open [Flutter](../mobile/flutter.md). For emulator QA, open [emulators](../mobile/emulators.md).

For framework-specific .NET cases, open [.NET testing](../services/dotnet.md#testing).
