# JavaScript and Node.js


| Skill                         | Install source    | Use when                                                                                                                    |
| ----------------------------- | ----------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `node`                        | `mcollina/skills` | Node.js with native TypeScript, streams, async lifecycles, modules, tests, performance, or logging recurs.                  |
| `nodejs-backend-patterns`     | `wshobson/agents` | A Node.js service repeatedly needs middleware, error, authentication, or API structure decisions across Express or Fastify. |
| `nodejs-core`                 | `mcollina/skills` | Work happens inside `nodejs/node`, a native addon, node-gyp, N-API, libuv, or a Node/V8 crash.                              |
| `linting-neostandard-eslint9` | `mcollina/skills` | ESLint 9 flat config or migration from legacy ESLint/Standard recurs.                                                       |
| `check-npm`                   | `grafana/skills`  | npm, pnpm, or Yarn configuration needs a supply-chain and lifecycle-script audit.                                           |


Use the package manager already selected by the repository. For pnpm, Bun, Deno, workspaces, and CI, open [build tooling](../infrastructure/build-tooling.md). For a particular server framework, open [backend](../services/backend.md).
