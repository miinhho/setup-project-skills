# Ruby and Rails

Match Ruby/Rails versions and existing conventions before proposing a skill. Language performance, refactoring, Rails application work, RSpec/Capybara tests, and Hotwire have separate scopes.

| Skill | Install source | Use when |
| --- | --- | --- |
| `ruby-optimise` | `pproenca/dot-skills` | Ruby performance optimization guidelines. |
| `ruby-refactor` | `pproenca/dot-skills` | Ruby refactoring guidelines from community best practices. |
| `rails-dev` | `pproenca/dot-skills` | Ruby on Rails performance and maintainability optimization guidelines for building backend APIs and frontend web applications. |
| `rails-testing` | `pproenca/dot-skills` | Ruby on Rails testing best practices for writing effective, maintainable test suites with RSpec. |
| `rails-hotwire` | `pproenca/dot-skills` | Ruby on Rails Hotwire best practices for building interactive applications with Turbo Drive, Turbo Frames, Turbo Streams, Turbo 8 morphing, and Stimulus controllers. |
