# Project skill map

Open only the fields matching the target repository's stack or recurring work. The fields and providers below are extensible: for an unlisted stack, follow the source search and comparison workflow in `SKILL.md` instead of substituting an unrelated skill. Each row links to candidate skills, not an installation preset. Propose a small project-specific set and get the user's explicit approval before installing anything.
